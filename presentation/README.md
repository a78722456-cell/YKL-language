# YKL 2.0 Presentation Deck (Web & PDF)

Интерактивная презентация проекта **Young Kazah Language (YKL / APL)** для питчей, хакатонов, конференций и демонстрации жюри.

## 🚀 Форматы

1. **Веб-версия:** [`index.html`](index.html)
   - Открывается в любом современном браузере без установки веб-серверов.
   - Поддерживает полноэкранный режим демонстрации (F11 / клавиша `F`).
   - Интерактивный график телеметрии полета дрона.
   - Интерактивная сетка обзора всех слайдов (клавиша `O` или `Esc`).

2. **Готовый PDF:** [`presentation.pdf`](presentation.pdf)
   - 12 страниц в формате альбомного листа 16:9 (Landscape).
   - Готов к отправке жюри, инвесторам или печати на раздаточных материалах.

---

## ⌨️ Управление во время выступления

| Клавиша | Действие |
| :--- | :--- |
| `→` / `Пробел` / `PageDown` | Следующий слайд |
| `←` / `Backspace` / `PageUp` | Предыдущий слайд |
| `F` | Полноэкранный режим (Fullscreen) |
| `O` / `Esc` | Сетка всех слайдов для быстрого перехода |
| `Home` / `End` | Переход на первый / последний слайд |
| `P` / Кнопка `PDF` в панели | Мгновенный экспорт или печать в PDF |

---

## 🛠️ Сборка нового PDF (при редактировании HTML)

```powershell
Start-Process -FilePath "C:\Program Files\Google\Chrome\Application\chrome.exe" `
  -ArgumentList "--headless=new", "--disable-gpu", "--no-pdf-header-footer", `
  "--print-to-pdf=presentation.pdf", "index.html" -Wait
```
